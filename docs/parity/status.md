# Radian vs Arc: parity status

Status of each of the 78 Arc features in [features.md](features.md), as of **2026-10-23**.

## How to read this

- **Done**: Radian does what Arc does. Any gap left is small, cosmetic or unmeasured.
- **Partial**: the feature exists, but a documented Arc behaviour is missing or works differently in a way a user would notice.
- **Missing**: not built.
- **Excluded**: deliberately not built. The Gap column gives the reason.

Each row cites the Orbe inventory ids ([arc-inventaire.md](../orbe/suivi/arc-inventaire.md), dated 8 Oct 2026) and was spot-checked against the code on 2026-10-23. Measured Arc 1.170 values come from [captures/layout/spec.md](captures/layout/spec.md) and [captures/colors/spec.md](captures/colors/spec.md).

File abbreviations: W = `src/main/window.js`, C = `src/main/commands.js`, M = `src/main/menu.js`, SH = `src/renderer/shell.js`, SC = `src/renderer/shell.css`, OV = `src/renderer/overlay.js`, L = `src/shared/locales.js`, ST = `src/main/store.js`.

## Engine limits

Things Electron cannot do without native code (a Node addon or a Chromium patch). Radian ships no native modules.

- **Haptics** (tab drag, drop, theme picker): Electron exposes no `NSHapticFeedbackManager`.
- **AppleScript dictionary**: needs an `.sdef` file plus `NSScriptCommand` handlers in native code.
- **Custom PiP window**: Chromium's Picture in Picture window has no API for position, size or controls, and `documentPictureInPicture.requestWindow()` fails in Electron.
- **Cast**: Electron ships without Chrome's media router and Cast support.
- **Chrome translate**: Chrome's built-in translation service is not part of Electron; Radian can only open a page in an online translator.
- **iCloud Keychain passkeys**: need Apple's browser passkey entitlement and native AuthenticationServices calls.
- **Per-site extension access and incognito switch**: Electron's extension support has no such controls.
- **Full-screen transition**: the macOS animation cannot be replaced.
