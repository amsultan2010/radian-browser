# Orbe's original docs

These are the docs of [Orbe](https://github.com/amadoubaui/orbe), the browser
Radian is forked from, written by Amadou Ba. They are in French and describe
Orbe as it was when Radian forked it (version 0.15.5), so they say "Orbe"
where the app is now called Radian. They are kept because they explain how
much of the code works and why.

| File | What it covers |
| --- | --- |
| [analyse-arc.md](analyse-arc.md) | Orbe's survey of Arc 1.166: menus, shortcuts and measurements, with Orbe's status for each. |
| [bloqueur.md](bloqueur.md) | The built-in ad and tracker blocker. |
| [extensions.md](extensions.md) | Chrome extension support and the extra `chrome.*` APIs Orbe adds to Electron. |
| [etude-extensions-et-distribution.md](etude-extensions-et-distribution.md) | Study of extensions, DRM (Widevine), Google sign-in and distribution on Electron. |
| [mots-de-passe.md](mots-de-passe.md) | The password manager and its threat model. |
| [securite-navigation.md](securite-navigation.md) | Threat notes for everyday browsing: permissions, certificates, pop-ups, downloads, links to other apps. |
| [feuille-de-route.md](feuille-de-route.md) | Orbe's roadmap. |
| [suivi/](suivi/) | Checklists of Arc features and improvements, with their status in Orbe. `node scripts/suivi.js` counts and ticks them. |
| [captures/](captures/) | Screenshots of Orbe's interface. |

Radian's own plan and Arc specs are in the [parent folder](../README.md).
